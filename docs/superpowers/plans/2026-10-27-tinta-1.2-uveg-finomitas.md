# Tinta 1.2 – Üveg téma + UI finomítás – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Selectable Apple-like "Üveg" theme, per-page ink motions, polished grades header and timetable.

**Architecture:** All new pure logic (formatting, colors, trend points, break spans, gaps, current lesson) lives in small helper files under `folio/lib/helpers/` so it is unit-testable from `folio/test/`. UI changes stay in the existing widgets in `folio_mobile_ui`. The glass look is gated by one getter, `isGlassTheme(context)`, so every other theme renders exactly as before.

**Tech Stack:** Flutter 3.47 / Dart, Provider, i18n_extension, flutter_test.

**Spec:** `docs/superpowers/specs/2026-10-27-tinta-1.2-uveg-finomitas-design.md`

## Global Constraints

- `AccentColor.uveg` is appended at the END of the enum (index 16). Existing indexes stay unchanged.
- Non-Üveg themes: no visual change (except the comma/labels/sparkline/break card/today underline/gap captions, which apply to every theme per spec).
- Blur (`BackdropFilter`) only on the navbar and the filter chips, never on list cards.
- Every motion runs at most once per page per app launch, and never when `MediaQuery.of(context).disableAnimations` is true.
- Hungarian UI copy is given exactly: "30 napja", "tárgyak átl.", "osztályátl.", "Átlagod", "X perc van hátra", "X perc szünet", "még X nap", "Következő óra", "Üveg".
- Tests: `cd folio && flutter test`. Commits stay local (branch `tinta`), no push.

## Review Focus

- Break day that runs to the end of the loaded week: the card shows the end as the last loaded day, and the next lesson is omitted. Must not crash.
- Lessons with `start.hour == 0` (KRÉTA placeholder times): no gap caption, never treated as "current".
- A subject with 0 or 1 grades: no sparkline (fewer than 2 points), nothing breaks.
- Switching from Üveg to another theme at runtime: blobs, glass navbar and transparent scaffold all revert without restart.
- Average exactly on an integer (5,00 / 3,00): the color equals that grade's color.

**Interfaces:**

  - `InkStroke({EdgeInsetsGeometry? padding, InkStyle style = InkStyle.pen, String? motionKey})`. If `motionKey` is non-null and `MotionOnce.shouldPlay(motionKey)` is false, the stroke appears already complete. `still` never animates.

Motions (mockup `mozgas-v2.html`):
- **drop**: a dot falls from the top to the line's y in 450 ms (easeIn), then the line spreads from the dot to full width in 600 ms (`Cubic(.2,.8,.2,1)`).
- **blot**: the full line, blur sigma 6→0, opacity 0→1, scaleX .6→1 from left, 800 ms easeOut (use `ImageFiltered` around the painter).

Call sites: messages = `drop`; absences, notes = `blot`; timetable, grades, settings, profile = `still`. The motionKey is the page name (`"home"`, `"messages"`, `"absences"`, `"notes"`); home passes `motionKey: "home"`.

### Task 4: Timetable helpers

**Files:**
- Create: `folio/lib/helpers/timetable_insights.dart`
- Test: `folio/test/timetable_insights_test.dart`

**Interfaces:**
- Produces:
  - `bool isNonSchoolDay(List<Lesson> day)`: day is non-empty and every lesson has `subject.id == ''` and `!isEmpty`.
  - `String breakName(String raw)`: strip every `(...)` group and trim. `"Őszi szünet (Nem órarendi nap) (Szerda)"` → `"Őszi szünet"`.
  - `class BreakSpan { final String name; final DateTime first, last; final int daysLeft; final double progress; final Lesson? nextLesson; }`
  - `BreakSpan breakSpanFor(List<List<Lesson>> days, int index, DateTime now)`:
    - The span extends over consecutive non-school days around `index` whose `breakName` is the same.
    - `daysLeft` = whole days from `now`'s date to `last`, inclusive (0 if `last` is before today).
    - `progress` = elapsed days / total days, clamped 0..1. It is 0 for a single day.
    - `nextLesson` = the first lesson with `subject.id != ''` in the days after `last`, else null.
  - `int? gapMinutes(Lesson before, Lesson next)`: null if either `start.hour == 0` / `end.hour == 0`, or if the gap ≤ 0.
  - `double? lessonProgress(Lesson l, DateTime now)`: null unless `start <= now < end` and `start.hour != 0`. Otherwise elapsed / total.
  - `int minutesLeft(Lesson l, DateTime now)`: ceil of minutes until `end`.

- [ ] **Step 1: Write failing tests** (build `Lesson` objects with the needed fields set):
  - `breakName` example above
  - Mon–Fri all "Őszi szünet (…)", `index` = Wed, now = Tue → `first` Mon, `last` Fri, `daysLeft` 4
  - single break day → `progress == 0`
  - Mon–Wed break + Thu real lesson → `nextLesson` = the Thu lesson
  - Mon–Fri break → `nextLesson == null`
  - `gapMinutes` 8:45→8:55 = 10; a midnight start → null
  - `lessonProgress` at 8:20 of 8:00–8:45 ≈ 0.444; `minutesLeft` = 25; outside the lesson → null
