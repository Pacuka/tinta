# Tinta 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Folio fork into "Tinta": its own Android package that installs next to Folio, new branding, three new built-in themes (Kobalt as default), and five small home-screen fixes.

**Architecture:** Only the Android `applicationId` changes. The Kotlin `namespace` and the MethodChannel names stay `app.zan1456.folio*`, so no native code moves. Themes extend the existing `AccentColor` enum. New values are appended so the stored enum indexes stay valid. Each theme's colors live in one new file. The home-screen fixes are local edits to existing widgets.

**Tech Stack:** Flutter 3 / Dart ^3.6, Material 3, provider, flutter_launcher_icons, flutter_native_splash, adb.

**Spec:** `docs/superpowers/specs/2026-10-25-tinta-1.0-design.md`

## Global Constraints

- App name `Tinta`. Android `applicationId` is `hu.pacuka.tinta`. `namespace` stays `app.zan1456.folio`.
- Theme colors, light/dark accent: Kobalt `#2440C8` / `#9DB0FF` on backgrounds `#F6F7F9` / `#101218`. Fekete-sárga `#121212` + `#FFE14D` / `#FFE14D`. Petrol `#0F5C66` / `#5FC9D4`, amber `#E0A526`.
- The default theme on a fresh install is Kobalt. Existing stored `accent_color` indexes must keep their meaning.
- Font: Outfit, bundled locally (OFL license file included).
- The "KRÉTA" logo never appears, and "KRÉTA" is never part of the app name.
- The about screen credits the lineage: Folio (Zan1456) ← Firka ← Filc. The AGPL-3 license stays.
- The update checker uses `https://api.github.com/repos/Pacuka/tinta/releases`.
- Firebase/FCM is off in 1.0. Crash reports are not sent to `api.firka.app` (it is not our backend).
- Only `folio/` (the phone app) is built. `folio_wear` and iOS are left untouched.
- Nothing is pushed to GitHub and the repository is not renamed without the user's explicit OK.

## Review Focus

1. **A user upgrading from Folio data, or one who picked a theme earlier:** the saved theme index must still map to the same theme. Appending to the enum covers this. A test pins the indexes (Task 4).
2. **Light/dark switch and the "system" mode on each new theme:** text must stay readable. The palette test checks that the accent-on-background contrast is ≥ 3:1 (Task 4).
3. **Very long homework titles (300+ characters) and empty titles:** the tile may grow to 2 lines and no further, with no overflow error. Covered by a widget test in Task 5.
4. **First launch with no network:** the update checker against the not-yet-existing `Pacuka/tinta` repo must fail silently (it returns 404 until the repo is renamed). Checked by running the app in Task 6.
5. **Installing next to an existing Folio:** both apps must run with separate data. This is a manual check on the phone in Task 6.

test('enum indexes of old values unchanged', () {
  expect(AccentColor.filc.index, 0);
  expect(AccentColor.adaptive.index, 11);
  expect(AccentColor.custom.index, 12);
  expect(AccentColor.kobalt.index, 13);
});
test('kobalt light/dark values from spec', () {
  expect(tintaPalette(AccentColor.kobalt, Brightness.light)!.accent, const Color(0xFF2440C8));
  expect(tintaPalette(AccentColor.kobalt, Brightness.dark)!.accent, const Color(0xFF9DB0FF));
  expect(tintaPalette(AccentColor.kobalt, Brightness.light)!.background, const Color(0xFFF6F7F9));

test('non-tinta accents return null', () {

});
test('accent vs background contrast >= 3 for all tinta themes', () {
  for (final c in [AccentColor.kobalt, AccentColor.feketeSarga, AccentColor.petrol]) {

    }
  }
});
